# 战斗界面与状态栏

## 布局

| 区域 | 内容 |
| --- | --- |
| 战场 | 己方从左到右是 4、3、2、1 号位，敌方是 1、2、3、4 号位。角色头顶显示红色生命条，性格位于姓名右侧，下方显示当前状态图标与层数。两侧保留空位。 |
| 左下 | 背包图标右侧显示前 16 件未装备的物品。下方四张己方角色卡按战场站位排列，各卡从左到右为 1 至 3 号装备槽、角色立绘、当前攻击与双抗。未布阵的队员显示在角色卡下方。 |
| 右下 | 战斗日志按时间刻显示行动者、目标、生命变化和决策理由。 |
| 顶栏 | 战前开始战斗，回合结束暂停时显示「下回合」，战后可重置演练。 |

## 职业边框

静态战斗立绘、装备缩略图和角色编辑页读取角色职业来绘制边框。战士用铜红铆钉与盾徽，法师用淡紫晶角和菱形纹，射手用绿叶角和箭徽，后勤用暖金圆角和星纹。立绘沿职业边框内沿裁切。战斗精灵图直接绘制在战场上，拖拽换位时以底色提示目标。空位使用中性细边。

## 操作

- 战前布阵在「角色编辑」页面完成。战斗页面仅在回合结束暂停时开放换位。
- 战斗中悬停下方立绘，可查看队员的生命、属性、性格、状态和装备。悬停装备图标可查看大图、名称和效果。共享背包从「角色编辑」里的角色面板打开。
- 回合结束暂停时，长按己方存活角色约 0.3 秒，再拖到另一名存活队员身上松开。成功交换一次后立即开始下一回合。也可以点顶栏「下回合」沿用当前站位。
- 状态栏列出当前状态图标与层数。悬停图标时弹出面板，展示大图标、名称、层数和效果。护盾图标显示当前值，倒下提示位于生命条。每次行动和装备效果会同步更新生命与状态。

## Buff 图标资源

`Assets/RaidPartyManager/Art/Buff` 收录策划表中的 16 种状态图标，文件名沿用表格的编号和名称，例如 `01-盛气.png`、`15-寒冷.png` 和 `16-冰冻.png`。原图是 1254 × 1254 的方形 PNG，通过 Git LFS 管理。Unity 使用 256 × 256 的单张 Sprite 导入配置，`.meta` 随源图一起提交。替换图标时保留对应的 `.meta`，以维持资源 GUID。

原图和生成记录保存在 Obsidian《讨伐队经理》。林道遭遇按状态类型引用这 16 个图标。缺少图标时，界面显示状态名称和层数。

## 角色战斗动画

战斗图集位于 `Assets/RaidPartyManager/Art/CombatSprites`。在角色资源中绑定主图集（8 列 × 4 行，依次为待机、出手、受伤、倒地）、宽幅攻击图集（4 列 × 2 行）和近战移动图集（3 列 × 2 行）。每套图集朝向右侧，各帧使用统一脚底线。受伤使用前四格，近战攻击用六帧步态接近目标和返回原位，远程出手在命中时移除投射物。

图鉴的 35 个角色都已绑定战斗图集。倒地按八帧播放，最后一帧保持在场。战斗内进阶或切换形态时，战场会换用对应角色的图集。

敌方使用独立的朝左图集。特殊行为在生效帧播放对应动作和效果，详见[敌人立绘与战斗动画](EnemyAnimation.md)。

## 非战斗时的角色编辑

战前和结算画面的顶栏提供「角色编辑」。独立页面从左到右排列 4、3、2、1 号位，角色姓名在立绘上方，当前生命在下方。空位保留，未布阵角色仍可从下方名单打开。

长按立绘约 0.3 秒后拖动。有队员的站位会互换，空位会接收队员，拖到「拖到此处移出站位」可让队员离开站位。点按角色在原页弹出装备面板。左侧展示立绘、攻击、防御、特防、当前生命及三个装备槽，右侧为共享背包，每页 4×4 格，只展示尚未装备的物品。关闭面板回到角色列表，点左上「返回」回原画面。

右键点队员打开完整角色名单，已入队的角色不可选择。替换后新队员满血上场并沿用该站位，原队员的装备回到共享背包。右键点未布阵队员也能替换。

「敌方编辑」的站位从左往右为 1 到 4 号。点立绘从九名敌人中替换，长按立绘拖动换位。准备完成后，开战使用编辑后的敌方阵容。

- 鼠标悬停物品格时显示图片、名称和描述。移出格子或开始拖拽时关闭详情。
- 按住物品约 300 毫秒后拖动。背包和角色装备槽之间可双向拖拽。目标为空时移动，已有装备时两件物品互换，被替换装备回到原背包格。拖到其他区域松开时取消。
- `CharacterEquipmentPopup` 记录背包格位置，并通过 `PartyRun.TryEquip` 完成装备更新。角色页和战斗界面共用同一份装备、生命与战利品。背包分页显示 49 种装备的对应立绘，开局每种 4 件。

## 数据与验证

- `BattleSimulator` 在行动事件中提供目标结算后的生命、剩余护盾和状态层数。回放使用这些数值刷新 `BattleUnitCard`。出手、投射物或近战归位，以及对应的受击或倒地动画播完后，界面立即播放下一次行动。装备和状态效果随对应行动或回合边界显示。
- 立绘通过 `CharacterAsset` 的 Portrait 字段配置。己方角色缩略图取自 Obsidian《讨伐队经理》的角色图鉴，Unity 版本存放在 `Assets/RaidPartyManager/PrototypeData/Portraits` 并由 Git LFS 管理。没有立绘的角色使用职业标记。
- Play Mode 用例 `BuiltSceneSupportsPreparationPlaybackLootAndReset` 检查战斗站位、职业边框、生命条、护盾变化、倒下、配装、回放和重置。
- Play Mode 用例 `PartyEditorOpensProfileAndSharedBackpackOutsideCombat` 覆盖 4×4 背包、悬停详情、短按不启动拖拽、长按移动、无效投放取消，以及已有装备互换后返回原背包格。它还验证退出弹窗后战场显示更新后的装备，结算掉落也会进入背包。
