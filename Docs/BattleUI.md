# 战斗界面与状态栏

## 布局

| 区域 | 内容 |
| --- | --- |
| 战场 | 己方从左到右是 4、3、2、1 号位，敌方是 1、2、3、4 号位。生命条在角色上方，状态栏在角色下方。两侧保留空位。 |
| 左下 | 四张己方装备卡按战场站位排列，每张含角色缩略图和三个装备槽。未布阵的队员显示在装备卡下方。 |
| 右下 | 战斗日志按时间刻显示行动者、目标、生命变化和决策理由。 |
| 顶栏 | 战前开始战斗，战中调速或跳到结算，战后重置演练。 |

## 职业边框

战斗站位、装备缩略图和角色编辑页读取角色职业来绘制同款边框。战士用铜红铆钉与盾徽，法师用淡紫晶角和菱形纹，射手用绿叶角和箭徽，后勤用暖金圆角和星纹。外框和立绘内沿使用同一组切角尺寸，战士 5、法师 9、射手 10、后勤 7，随卡宽等比缩放。立绘沿内沿裁切，斜角与圆角外不会显示图片。空位使用中性细边。阵营仍由战场两侧与生命条区分，选中态显示在站位按钮或装备卡外框上。

## 操作

- 点左下队员缩略图选择队员，再点战场上的「放到 N 号位」。目标位被占用时交换两人。「移出站位」会留下空位，所有存活队员完成布阵后才能开战。
- 在战前主画面，点某个装备槽可打开共享背包。选择装备会把该实例放进选中的槽，原持有者的对应槽随即腾空。「卸下」把装备留在背包里。角色编辑弹窗使用下文的拖拽规则。
- 战中状态栏显示「正常」「护盾 N」「倒下」，空位用「—」。护盾增加或吸收伤害时更新数值。结算画面保留本场倒下状态和剩余生命。

## 非战斗时的角色编辑

战前和结算画面的顶栏提供「角色编辑」。独立页面从左到右排列 4、3、2、1 号位，角色姓名在立绘上方，当前生命在下方。空位保留，未布阵角色仍可从下方名单打开。

点角色在原页弹出装备面板。左侧展示立绘、攻击、防御、特防、当前生命及三个装备槽，右侧为共享背包，每页 4×4 格，只展示尚未装备的物品。关闭面板回到角色列表，点左上「返回」回原画面。

- 鼠标悬停物品格时显示图片、名称和描述。移出格子或开始拖拽时关闭详情。
- 按住物品约 300 毫秒后拖动。背包和角色装备槽之间可双向拖拽。目标为空时移动，已有装备时两件物品互换，被替换装备回到原背包格。拖到其他区域松开时取消。
- `CharacterEquipmentPopup` 记录背包格位置，并通过 `PartyRun.TryEquip` 完成装备更新。角色页和战斗界面共用同一份装备、生命与战利品。当前道具图标为演练用的盾牌与徽印。

## 数据与验证

- `BattleSimulator` 在行动事件中提供目标结算后的生命和剩余护盾。回放使用这些数值刷新 `BattleUnitCard`。回放速度不参与模拟计算。
- 立绘通过 `CharacterAsset` 的 Portrait 字段配置。己方四张缩略图取自 Obsidian《挑战者》的角色图鉴，Unity 版本存放在 `Assets/RaidPartyManager/PrototypeData/Portraits` 并由 Git LFS 管理。没有立绘的角色使用职业标记。
- Play Mode 用例 `BuiltSceneSupportsPreparationPlaybackLootAndReset` 检查战斗站位、职业边框、生命条、护盾变化、倒下、配装、回放和重置。
- Play Mode 用例 `PartyEditorOpensProfileAndSharedBackpackOutsideCombat` 覆盖 4×4 背包、悬停详情、短按不启动拖拽、长按移动、无效投放取消，以及已有装备互换后返回原背包格。它还验证退出弹窗后战场显示更新后的装备，结算掉落也会进入背包。
