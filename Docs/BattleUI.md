# 战斗界面与状态栏

## 布局

| 区域 | 内容 |
| --- | --- |
| 背景 | 按原始比例铺满整屏，位于角色、特效和界面下方。 |
| 战场 | 己方从左到右是 4、3、2、1 号位，敌方是 1、2、3、4 号位。角色上方显示姓名。红色生命条、状态图标和层数位于角色下方。空位留白。侦察后或开战时才显示敌方角色。 |
| 左下 | 贴近屏幕底边的四张紧凑的己方角色卡按战场站位排列，各卡从左到右为 1 至 3 号装备槽、按原始比例完整显示的立绘、能量格。未布阵的队员显示在角色卡下方。 |
| 右下 | 与角色卡拉开间距并在底边对齐的羊皮纸底的战斗日志按时间刻显示行动者、目标、生命变化和决策理由。 |
| 顶栏 | 显示金币和最多 16 格未装备的物品、未使用的技能书。重复物品逐件显示。战前、关卡、事件、营地、城镇和商店的队伍编辑图标位于金币与背包之间。开始战斗按钮位于顶栏，右端的设置可返回主菜单。战斗开始后，「暂停」按钮位于顶栏下方中央。 |
| 胜利弹窗 | 在屏幕中央点击战利品或金币的图标与文字领取。领完自动返回，精英战和 Boss 战只领取一个候选。 |

## 职业边框

静态战斗立绘、装备缩略图和角色编辑页读取角色职业来绘制边框。战士用铜红铆钉与盾徽，法师用淡紫晶角和菱形纹，射手用绿叶角和箭徽，后勤用暖金圆角和星纹。立绘沿职业边框内沿裁切。战斗精灵图直接绘制在战场上，拖拽换位时以底色提示目标。角色编辑页以细边标出可拖放的空位。

## 操作

- 战前布阵在「角色编辑」页面完成。战斗页面仅在回合结束暂停时开放换位。
- 战斗中悬停下方立绘，可查看队员的生命、属性、性格、状态、已学技能与装备。悬停装备图标可查看大图、名称和效果。共享背包从「角色编辑」里的角色面板打开。
- 战斗自动推进。点「暂停」后会打完当前回合再停下，期间可取消预约。暂停时可点「继续」，也可长按己方存活角色约 0.3 秒，拖到另一名存活队员身上松开。换位成功后立即继续自动战斗。
- 状态栏列出当前状态图标与层数。悬停图标时弹出面板，展示大图标、名称、层数和效果。护盾图标显示当前值，倒下提示位于生命条。每次行动和装备效果会同步更新生命与状态。

## Buff 图标资源

`Assets/RaidPartyManager/Art/Buff` 收录策划表中的 16 种状态图标，文件名沿用表格的编号和名称，例如 `01-盛气.png`、`15-寒冷.png` 和 `16-冰冻.png`。原图是 1254 × 1254 的方形 PNG，通过 Git LFS 管理。Unity 使用 256 × 256 的单张 Sprite 导入配置，`.meta` 随源图一起提交。替换图标时保留对应的 `.meta`，以维持资源 GUID。

原图和生成记录保存在 Obsidian《讨伐队经理》。林道遭遇按状态类型引用这 16 个图标。缺少图标时，界面显示状态名称和层数。

## 角色战斗动画

战斗图集位于 `Assets/RaidPartyManager/Art/CombatSprites`。在角色资源中绑定主图集（8 列 × 4 行，依次为待机、出手、受伤、倒地）、宽幅攻击图集（4 列 × 2 行）和近战移动图集（3 列 × 2 行）。每套图集朝向右侧，各帧使用统一脚底线。受伤使用前四格，近战攻击用六帧步态接近目标和返回原位，远程出手在命中时移除投射物。

进入战斗场景时，己方从左侧、已侦察的敌方从右侧，按各自 1 → 4 号位快速步行入场。未侦察的敌人开战揭晓后入场。空位跳过，第一回合等双方就位后开始。

35 个己方角色与形态、9 名敌人均有入场步态。24 套已有的六帧步行图集直接用于入场，其余 20 个形态从现有像素图渲染六个步行姿势，按职业区分步幅与抬脚高度。倒地按八帧播放，最后一帧保持在场。战斗内进阶或切换形态时，战场会换用对应角色的图集。

敌方使用独立的朝左图集。特殊行为在生效帧播放对应动作和效果，详见[敌人立绘与战斗动画](EnemyAnimation.md)。

技能书施放后，战斗回放在实际生效的单位位置播放技能特效。元素石英将直接技能命中的火焰与雷电互换时，命中特效、飘字和伤害类型一致。延后生效的群攻技能在下一次攻击命中时播放。详见[技能特效与动画预览](SkillEffects.md)。

命中特效图集是可选资源。没有独立图集时（如天弓的贯穿箭），回放跳过额外图层，弹道、命中扣血、受击和飘字照常播放。天弓的 Play Mode 用例覆盖无图集时多个目标依次扣血及弹道收尾。

## 非战斗时的角色编辑

战前和败北结算画面的顶栏提供「角色编辑」。独立页面从左到右排列 4、3、2、1 号位，角色姓名在立绘上方，当前生命在下方。空位保留，未布阵角色仍可从下方名单打开。

长按立绘约 0.3 秒后拖动。有队员的站位会互换，空位会接收队员，拖到「拖到此处移出站位」可让队员离开站位。点按角色在原页弹出装备面板。左侧展示立绘、横排的攻击和双抗、特性描述，旁边从上到下是装备槽与技能槽。右侧共享背包按装备、技能书两个书签分开，每页 4×4 格。关闭面板回到角色列表，点右上「返回」（或按 Esc）回原画面。编辑页内的直达主菜单按钮已移除。

右键点队员打开完整角色名单，已入队的角色不可选择。替换后新队员满血上场并沿用该站位，原队员的装备回到共享背包。右键点未布阵队员也能替换。

演练时，在顶栏的设置中打开「敌方编辑」。站位从左往右为 1 到 4 号。可从下拉列表选择[预设敌阵](EnemyFormations.md)并点击「载入敌阵」，也可以点立绘替换单个敌人，长按立绘拖动换位。右上「返回」后，此阵容用于下一战。

- 鼠标悬停物品格时显示图片、名称和描述。移出格子或开始拖拽时关闭详情。
- 按住物品约 300 毫秒后拖动。背包和角色装备槽之间可双向拖拽。目标为空时移动，已有装备时两件物品互换，被替换装备回到原背包格。拖到其他区域松开时取消。
- 技能书可放进空槽或已有技能的槽。覆盖会消耗新书并遗忘旧技能，旧书不会回到背包。职业限制和同一角色不能重复学习的规则仍然生效。
- `CharacterEquipmentPopup` 记录背包格位置，并通过 `PartyRun.TryEquip`、`TryLearnSkill` 写入装备和技能。角色页和战斗界面共用同一份装备、生命与战利品。每次打开己方编辑页时，共享背包的每种装备和技能书至少提供 4 份可用副本。离开编辑页会收回未使用的测试副本，已穿戴的测试装备和已学技能会保留。

## 数据与验证

- `BattleSimulator` 在行动事件中提供目标结算后的生命、剩余护盾和状态层数。回放使用这些数值刷新 `BattleUnitCard`。出手、投射物或近战归位，以及对应的受击或倒地动画播完后，界面立即播放下一次行动。装备和状态效果随对应行动或回合边界显示。
- 立绘通过 `CharacterAsset` 的 Portrait 字段配置。己方角色缩略图取自 Obsidian《讨伐队经理》的角色图鉴，Unity 版本存放在 `Assets/RaidPartyManager/PrototypeData/Portraits` 并由 Git LFS 管理。没有立绘的角色使用职业标记。
- Play Mode 用例 `BuiltSceneSupportsPreparationPlaybackLootAndReset` 检查战斗站位、职业边框、生命条、护盾变化、倒下、配装、回放和重置。
- Play Mode 用例 `PartyEditorOpensProfileAndSharedBackpackOutsideCombat` 覆盖 4×4 背包、悬停详情、短按不启动拖拽、长按移动、无效投放取消，以及已有装备互换后返回原背包格。它还验证退出弹窗后战场显示更新后的装备，结算掉落也会进入背包。
