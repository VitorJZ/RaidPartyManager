# 战斗界面与状态栏

## 布局

| 区域 | 内容 |
| --- | --- |
| 战场 | 己方从左到右是 4、3、2、1 号位，敌方是 1、2、3、4 号位。生命条在角色上方，状态栏在角色下方。两侧保留空位。 |
| 左下 | 四张己方装备卡按战场站位排列，每张含角色缩略图和三个装备槽。未布阵的队员显示在装备卡下方。 |
| 右下 | 战斗日志按时间刻显示行动者、目标、生命变化和决策理由。 |
| 顶栏 | 战前开始战斗，战中调速或跳到结算，战后重置演练。 |

## 操作

- 点左下队员缩略图选择队员，再点战场上的「放到 N 号位」。目标位被占用时交换两人。「移出站位」会留下空位，所有存活队员完成布阵后才能开战。
- 点某个装备槽打开共享背包。选择装备会把该实例放进选中的槽，原持有者的对应槽随即腾空。「卸下」把装备留在背包里。
- 战中状态栏显示「正常」「护盾 N」「倒下」，空位用「—」。护盾增加或吸收伤害时更新数值。结算画面保留本场倒下状态和剩余生命。

## 数据与验证

- `BattleSimulator` 在行动事件中提供目标结算后的生命和剩余护盾。回放使用这些数值刷新 `BattleUnitCard`。回放速度不参与模拟计算。
- 立绘通过 `CharacterAsset` 的 Portrait 字段配置。己方四张缩略图取自 Obsidian《挑战者》的角色图鉴，Unity 版本存放在 `Assets/RaidPartyManager/PrototypeData/Portraits` 并由 Git LFS 管理。没有立绘的角色使用职业标记。
- Play Mode 用例 `BuiltSceneSupportsPreparationPlaybackLootAndReset` 检查站位顺序、生命条与状态栏的位置，并覆盖扣血、护盾从 4 降到 3、倒下状态、装备转交、回放和重置。
