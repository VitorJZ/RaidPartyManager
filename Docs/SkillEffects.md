## 资源与播放

- 图集在 `Assets/RaidPartyManager/Art/SkillEffects`。每套是 1152 × 96 的透明 PNG，从左到右 12 帧，每帧 96 × 96。纹理使用点过滤、原始尺寸、RGBA 和无 Mipmap 设置。替换同一技能的图集时保留其 `.meta`。
- 在 `SkillCatalog` 的技能条目上设置 `Battle Effect`。战斗按技能书 ID（例如 `skill-book-07`）查纹理。万箭齐发、星陨术、横扫千军共用玩法效果，但分别保留技能书 ID，因而播放不同动画。
- 治疗、伤害和状态用结算事件中的目标定位。蓄势提示、金钟罩和吞食尸体使用纯视觉事件。未生效的状态和未命中的后续横扫不产生目标动画。护盾等免伤仍可显示命中反馈。
- 回放在结算点按目标播放图集。标准时长 0.64 秒，随战斗动画速度和暂停状态变化。结束、退场或重置时清理效果。特效与动画计时由界面处理，技能费用和结果仍由战斗模拟器结算。

## 修改与验证

修改 [生成脚本](../Tools/GenerateSkillEffects.py) 中对应编号的绘制和配色。使用安装了 Pillow 的 Python 3.10+ 从项目根目录运行 `python Tools/GenerateSkillEffects.py --preview`，生成图集与预览。

Unity Edit Mode 检查 20 套图集的透明通道和尺寸，并验证范围技能的目标及三种蓄势技能的延后触发。Play Mode 在战斗场景装备「战争咆哮」技能书，验证图集换帧并在回合结束前清理。
