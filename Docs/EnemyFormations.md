# 敌阵预设

**试玩**：主菜单进入「低语墓园」或普通战斗演练，在「设置 → 敌方编辑」选中一套预设并点击「载入敌阵」，再点右上「返回」开战。演练随机开局只抽普通预设，选择精英或首领后可以手调站位及敌人。载入会替换当前演练敌阵；手调或载入后，该阵在本次 Play 中保留。正式讨伐从码头当前等级的预设中抽整组，同一战斗节点反复读取使用已选阵容。

**人数缩放**：码头普通战按实际出战人数保留前 1～4 名。精英和首领总人数为出战人数减 1（最少 1，最多 3，同时受四格容量限制），从阵尾移除多余随从。升阶试炼仅出精英主敌。演练载入使用下表的完整阵容。

**来源和维护**：墓园 10 套沿用[固定阵容难度试算](WhisperingGraveyard.md#验证)的成员和站位；码头保留原普通对照阵，参考遭遇笔记里的绕后、弩手与治疗搭配，并按现行码头图鉴补全覆盖 23 名敌人的编队。未改变个体属性或行动。码头在 `RoadsideEncounter.asset` 的 `enemyFormations` 中配置；墓园源为 `WhisperingGraveyard.json` 的 `formations`，由 `Tools/BuildWhisperingGraveyard.py` 写入演练资源。`EncounterAsset` 通过角色 ID 从本区目录解析成员；`EnemyFormation` 校验重复成员、级别与占格，`AdventureRun` 只负责抽取、人数缩放和缓存。历史数值报告保留其原有抽样条件，不当作预设上线后的通关率。
