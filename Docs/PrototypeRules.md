# 首期玩法规则

策划来源是 Obsidian《挑战者》中的《自动战斗》《原型计划与待定事项》《队伍与招募》《装备与物品》和《角色图鉴》。这份文档描述仓库里实际能试玩的范围。

## 策划沿用与更新

- 一行对阵，每侧最多四人，1 号靠战场中央。空位和倒下单位会被跳过。
- 队员由 AI 自主决策，首期玩家负责布阵与配装。六种战斗性格均进入战斗模拟。
- 每人三个装备槽。装备实例归共享背包所有，可以转交。战斗胜利可掉落装备。队员不会通过战斗获得经验或永久属性增长，后续通过道具和事件进化。
- 当前生命战后写回。倒下的队员保留在队里，清空站位。首期演练只有一场遭遇，重置会清空演练期间的生命与装备变化。

## 战斗原型默认值

- 首次行动在第一个行动间隔结束时发生。冷却从技能实际使用的时间刻计算。技能和普攻共用一次行动机会，技能等目标或等冷却时仍可普攻。同刻先己后敌，每侧按站位升序结算。
- **伤害** = `max(1, 攻击 + 技能修正 - 对应防御)`。物理走防御，法术走特防。护盾先吸收伤害，伤害与治疗均按实际生命变化记录。护盾耗尽前保留，重新施加只在能增加护盾时合法，刷新至技能的固定值。
- **候选顺序**是就绪且合法的技能、普攻，各自按站位从近到远；固定前排或队尾的招式只产生一个候选。等分沿用候选顺序。治疗只选择仍存活且未满血的友方。装备增加生命上限时不自动回复生命，移除装备或切换形态时将当前生命限制在新上限内。
- 任何一方全灭立即结算。双方全灭判失败。首期单目标效果不会同时击倒双方，结算类型仍能表达这种结果。时间上限内允许在最后一刻行动，仍未分胜负则超时失败。演练为 200 刻，正常回放每秒 10 刻。

| 性格 | 有合法候选时的优先项 |
|---|---|
| 激进 | 扣除现有护盾后预计伤害最高的攻击 |
| 慎重 | 能增加自己防护的行动，包括合法的自疗或护盾 |
| 鲁莽 | 优先攻击，即使可自疗 |
| 温柔 | 优先治疗生命比例最低的可治疗队友 |
| 配合 | 优先追击最近被其他队友攻击过且仍能合法攻击的敌人 |
| 冷静 | 优先攻击生命比例最低的合法敌人 |

## 演练内容

林道遭遇战初始队伍是篝火守夜人、星辉术师、晨曦圣女、银叶射手。敌人是拦路蛮兵和使用固定队尾目标的绕后猎手。背包初始有精钢壁垒（防御、特防各 +1），胜利时掉落狂战士之印（攻击 +3）。角色与技能数值可在 Unity 的 `PrototypeData` 中调整，当前为演练数据。

战斗界面的状态栏显示现有的正常、护盾和倒下状态。参阅 [战斗界面与状态栏](BattleUI.md)。

新增敌人的方案与难度试算在 Obsidian《挑战者》的《敌人图鉴》中。当前 Unity 演练使用上面列出的两个敌人。招募、地图和区域、完整特性与状态效果、进化触发与分支属于后续开发。
