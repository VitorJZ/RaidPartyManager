# 首期玩法规则

策划来源是 Obsidian《讨伐队经理》中的《自动战斗》《原型计划与待定事项》《队伍与招募》《装备与物品》和《角色图鉴》。这份文档描述仓库里实际能试玩的范围。

## 策划沿用与更新

- 一行对阵，每侧最多四人，1 号靠战场中央。空位和倒下单位会被跳过。
- 队员由 AI 自主决策，玩家战前布阵与配装。每回合结束后可交换两名存活队员的位置，换位成功即开始下一回合。队员的战斗性格采用图鉴里的八种设定。
- 每人三个装备槽。装备实例归共享背包所有，可以转交。战斗胜利可掉落装备。队员不会通过战斗获得经验或永久属性增长，后续通过道具和事件进化。
- 参战队员保留战斗结束时的站位。存活队员保留剩余生命，阵亡队员在战后以 1 点生命复活。旧战斗演练只有一场遭遇；「事件选择 → 关卡试游」已接入十关路线，沿用战后剩余生命。重置演练恢复生命和站位，配装与战利品随本次 Play 保留。

## 战斗原型默认值

- 双方每名存活角色每回合最多行动一次。每回合先结算己方，再结算敌方，各侧独立随机排序。队员选择普攻、特性行动或已学技能。敌方按专属行为和目标规则行动，每回合从技能和普攻中执行一次。上一名角色的行动动画结束后，界面立即播放下一次行动。内部每回合推进存活角色中最大的行动间隔，供敌方技能冷却和战斗时限使用。
- **能量**默认上限为 2，余响圣杯把装备者上限设为 4。战斗栏右侧支持显示 2～8 格，可用格为亮紫色，已消耗格为白色。已学技能消耗对应能量并用掉当回合的行动，施放该回合也不会触发普攻反击。能量跨回合保留，战斗结束补满。
- **伤害** = `max(1, 攻击 + 技能修正 - 对应防御)`。物理伤害使用防御，魔法与火焰伤害使用特防，默认法师攻击为魔法伤害。混合伤害的各部分分别计算抗性和倍率，再合并为一次命中并结算护盾和生命。伤害与治疗按实际生命变化记录。护盾耗尽前保留，重新施加只在能增加护盾时合法，刷新至技能的固定值。
- **候选顺序**是合法的特性行动或就绪的敌方技能，再列出普攻，各自按站位从近到远。固定前排或队尾的招式只产生一个候选。等分沿用候选顺序。治疗只选择仍存活且未满血、可恢复生命的友方。装备增加生命上限时不自动回复生命，移除装备或切换形态时将当前生命限制在新上限内。
- 任何一方全灭立即结算。双方全灭判失败。时间上限内允许在最后一刻行动，仍未分胜负则超时失败。码头和正式讨伐使用 200 逻辑刻，墓园演练使用 400 逻辑刻。

| 性格 | 有合法候选时的优先项 |
|---|---|
| 胆小 | 受到敌方一次至少 7 点生命伤害，或回合结束时生命低于一半，退到可用的最后方位置 |
| 记仇 | 优先攻击最后对自己造成伤害的敌人 |
| 谨慎 | 优先攻击当前生命值最低的合法目标 |
| 固执 | 开战后锁定站位，自动退位和玩家换位均会避开 |
| 急躁 | 有已就绪且合法的技能时优先使用 |
| 专注 | 优先继续攻击上一次选定且仍可攻击的目标 |
| 隐忍 | 有普攻能击倒目标时优先保留已学技能 |
| 贪心 | 优先有效伤害，等效时选溢出更少的一击。能治疗生命不超过 25% 的队友时优先救援 |

## 装备交互采用的原型规则

同一角色在同一时机触发的装备，按 1、2、3 号槽依次结算。每件装备的追加效果在该槽内结算，红绳共享的装备随后按来源的槽位顺序结算。贪婪药水会影响其后获得的状态，已结算的药水保留当时的层数。蓝祭祀面具重复回合结束时的结算顺序。

- 同名装备允许重复配装，数值和触发次数按件结算。药水在战斗开始触发后从装备槽和共享背包消耗。浑浊的水与红绳仍结算额外效果，每瓶药水只扣一次。每个万能药瓶为每瓶药水各判定一次 50% 的保留概率。寻人启事可重复触发，精灵护符每件每场可挡一次致命伤害。疾风手套在原行动内追加攻击。
- 红绳共享给紧邻前一格的存活队友，并同步生命损失。前一格为空或队友倒下时，连结失效。守护者之旗覆盖所有后方存活队友。火焰和雷电戒指同时装备时按装备槽顺序取第一个转换伤害。火焰走特防，雷电无视防御和特防。洞察图腾优先标记最前方的存活敌人。晨曦圣女和神恩主祭的治疗特性每回合都可选，消耗本次行动，基础治疗量等于当前攻击力。反叛者耳坠把治疗转换为魔法伤害，AI 只会对存活敌人选用这项招式。
- 第三层寒冷转为冰冻并清空寒冷。仍有寒冷时，每层额外增加 50% 所受火焰伤害，并在这次命中后清空寒冷。冰冻时，下一次命中中的火焰伤害乘以 3，其他伤害乘以 2，命中后解除冰冻。余烬在命中时消耗，永恒之火会保留余烬。荆棘反击结算物理伤害。回合结束效果结算后再统一处理状态衰减。
- 攻击选目标时，会跳过佩戴隐匿披风的敌人。存活敌人都佩戴时，照常选择目标。全体目标效果仍可命中。处刑者面具首击按目标最大生命值的 10% 结算真实伤害，护盾照常抵挡。传国玉玺合计双方存活同职业角色的攻击力，包含装备者。传话筒每回合随机传递给一名有空装备槽的存活队友。古树根茎会锁定装备者的站位，战中换位和战前拖拽均受限制。
- 救援池包括林道遭遇配置中的基础角色。装备寻人启事后可空一个站位开战。战后存活的召唤队友入队，满员时占用倒下或未布阵队员的名额，原装备留在背包。
- 巫医玩偶可用遭遇资源中的初始中毒测试。在 Unity 的 `RoadsideEncounter` 中为携带玩偶的队员设置 `Starting Statuses → Poison` 与层数。

## 演练内容

独立演练开始时，己方从 35 名图鉴角色中不重复抽取 4 名，敌方从所选区域的普通敌人中不重复抽取 4 名。码头敌人池有 23 名，墓园有 30 名。「重置演练」只重抽未编辑的一方。测试背包有 50 种装备各 4 件，已实现的技能书各一本，胜利时额外掉落狂战士之印。可在 Unity 的 `PrototypeData` 中调整角色。寻人启事的招募池包括基础形态，进阶资源也由遭遇加载。敌方阵容在开战时揭晓，存活的情报官可以提前展示。独立演练可从「敌方编辑」查看并替换敌人。

战斗界面的状态栏显示状态名称、层数、护盾和倒下情况。参阅 [战斗界面与状态栏](BattleUI.md)。

正式讨伐使用弥雾码头十关路线。低语墓园可从主菜单独立试玩。[码头规则](DockAdventure.md) · [墓园图鉴](WhisperingGraveyard.md) · [数值测试报告](Balance/2026-11-20.md)

命运编织者可在一场战斗内触发已有进阶分支，天弓与地煞也在本场战斗内互换形态。天弓会击中站在自己前方的两侧单位，地煞借用最近的后方队友攻击力。颂歌在盛气、迅捷、坚毅、不灭、余烬和荆棘之间抽取，施加 1 层。
