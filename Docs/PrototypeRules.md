# 首期玩法规则

策划来源是 Obsidian《讨伐队经理》中的《自动战斗》《原型计划与待定事项》《队伍与招募》《装备与物品》和《角色图鉴》。这份文档描述仓库里实际能试玩的范围。

## 策划沿用与更新

- 一行对阵，每侧最多四人，1 号靠战场中央。空位和倒下单位会被跳过。
- 队员由 AI 自主决策，玩家战前布阵与配装。每回合结束后可交换两名存活队员的位置，换位成功即开始下一回合。六种战斗性格均进入战斗模拟。
- 每人三个装备槽。装备实例归共享背包所有，可以转交。战斗胜利可掉落装备。队员不会通过战斗获得经验或永久属性增长，后续通过道具和事件进化。
- 当前生命和幸存队员的站位在战后写回。倒下的队员保留在队里，清空站位。首期演练只有一场遭遇。重置演练恢复生命和站位，配装与战利品随本次 Play 保留。

## 战斗原型默认值

- 双方每名存活角色每回合最多行动一次。每回合先结算己方，再结算敌方，各侧独立随机排序。技能和普攻共用一次行动机会，技能等目标或等冷却时仍可普攻。界面每两次角色行动间隔 3 秒。内部每回合推进存活角色中最大的行动间隔，供技能冷却和战斗时限使用。
- **伤害** = `max(1, 攻击 + 技能修正 - 对应防御)`。物理伤害使用防御，魔法与火焰伤害使用特防，默认法师攻击为魔法伤害。混合伤害的各部分分别计算抗性和倍率，再合并为一次命中并结算护盾和生命。伤害与治疗按实际生命变化记录。护盾耗尽前保留，重新施加只在能增加护盾时合法，刷新至技能的固定值。
- **候选顺序**是就绪且合法的技能、普攻，各自按站位从近到远；固定前排或队尾的招式只产生一个候选。等分沿用候选顺序。治疗只选择仍存活且未满血的友方。装备增加生命上限时不自动回复生命，移除装备或切换形态时将当前生命限制在新上限内。
- 任何一方全灭立即结算。双方全灭判失败。首期单目标效果不会同时击倒双方，结算类型仍能表达这种结果。时间上限内允许在最后一刻行动，仍未分胜负则超时失败。演练上限为 200 逻辑刻。

| 性格 | 有合法候选时的优先项 |
|---|---|
| 激进 | 扣除现有护盾后预计伤害最高的攻击 |
| 慎重 | 能增加自己防护的行动，包括合法的自疗或护盾 |
| 鲁莽 | 优先攻击，即使可自疗 |
| 温柔 | 优先治疗生命比例最低的可治疗队友 |
| 配合 | 优先追击最近被其他队友攻击过且仍能合法攻击的敌人 |
| 冷静 | 优先攻击生命比例最低的合法敌人 |

## 装备交互采用的原型规则

同一角色在同一时机触发的装备，按 1、2、3 号槽依次结算。每件装备的追加效果在该槽内结算，红绳共享的装备随后按来源的槽位顺序结算。贪婪药水会影响其后获得的状态，已结算的药水保留当时的层数。蓝祭祀面具重复回合结束时的结算顺序。

- 同名装备允许重复配装，数值和触发次数按件结算。药水在战斗开始触发后从装备槽和共享背包消耗。浑浊的水与红绳仍结算额外效果，每瓶药水只扣一次。每个万能药瓶为每瓶药水各判定一次 50% 的保留概率。寻人启事可重复触发，精灵护符每件每场可挡一次致命伤害。疾风手套在原行动内追加攻击。
- 红绳共享给最近的前方存活队友，并同步生命损失。守护者之旗覆盖所有后方存活队友。火焰和雷电戒指同时装备时按装备槽顺序取第一个转换伤害。火焰走特防，雷电无视防御和特防。洞察图腾优先标记最前方的存活敌人。晨曦圣女和神恩主祭的基础治疗量等于当前攻击力。反叛者耳坠把治疗转换为魔法伤害，AI 只会对存活敌人选用这项招式。
- 第三层寒冷转为冰冻并清空寒冷。仍有寒冷时，每层额外增加 50% 所受火焰伤害，并在这次命中后清空寒冷。冰冻时，下一次命中中的火焰伤害乘以 3，其他伤害乘以 2，命中后解除冰冻。余烬在命中时消耗，永恒之火会保留余烬。荆棘反击结算物理伤害。回合结束效果结算后再统一处理状态衰减。
- 攻击选目标时，会跳过佩戴隐匿披风的敌人。存活敌人都佩戴时，照常选择目标。全体目标效果仍可命中。处刑者面具首击按目标最大生命值的 10% 结算固定伤害，护盾照常抵挡。传国玉玺合计双方存活同职业角色的攻击力，包含装备者。传话筒每回合随机传递给一名有空装备槽的存活队友。古树根茎会锁定装备者的站位，战中换位和战前拖拽均受限制。
- 救援池包括林道遭遇配置中的基础角色。装备寻人启事后可空一个站位开战。战后存活的召唤队友入队，满员时占用倒下或未布阵队员的名额，原装备留在背包。
- 巫医玩偶可用遭遇资源中的初始中毒测试。在 Unity 的 `RoadsideEncounter` 中为携带玩偶的队员设置 `Starting Statuses → Poison` 与层数。

## 演练内容

林道遭遇战初始队伍是篝火守夜人、星辉术师、晨曦圣女、银叶射手。敌人是拦路蛮兵和使用固定队尾目标的绕后猎手。测试背包初始有 44 种装备各 4 件，胜利时额外掉落狂战士之印。可在 Unity 的 `PrototypeData` 中调整角色与技能。寻人启事的招募池包括基础形态，进阶资源也由遭遇加载。敌方阵容在开战时揭晓，存活的情报官可以提前展示。

战斗界面的状态栏显示状态名称、层数、护盾和倒下情况。参阅 [战斗界面与状态栏](BattleUI.md)。

新增敌人的方案与难度试算在 Obsidian《讨伐队经理》的《敌人图鉴》中。当前 Unity 演练使用上面列出的两个敌人。招募、地图和区域、常驻进阶仍待开发。命运编织者可在一场战斗内触发已有进阶分支，天弓与地煞也在本场战斗内互换形态。天弓会击中站在自己前方的两侧单位，地煞借用最近的后方队友攻击力。颂歌在盛气、迅捷、坚毅、不灭、余烬和荆棘之间抽取，施加 1 层。
