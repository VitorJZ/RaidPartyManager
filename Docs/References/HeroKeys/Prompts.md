# 角色关键帧重生成提示词

使用 Codex 内置 ImageGen。参考图为角色现有战斗像素图（左）与立绘（右），另附破阵先锋原始 8×4 图集或 3×2 步行图集作为版式示例。生成结果由 `Tools/ImportHeroKeys.py` 清理 Alpha、去除跨格残片、对齐现有待机首帧的高度、脚底线与中心，再交给 `Tools/AnimationCels.py` 烘焙。

深海轻语乘浪移动，不单独生成步行图，步行图集取前 6 个待机关键帧。
