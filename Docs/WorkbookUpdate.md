# 图鉴更新

以 2026 年 11 月 18 日的《讨伐队经理-图鉴.xlsx》为准。与上次装备定价时的快照相比，本次改动集中在装备、技能和性格。角色、敌人、区域和状态的规则表沿用原有内容。

## 装备

演练背包有下列 5 种装备，每种 4 件。档位用于战斗掉落。下表中 T1、T2、T3 装备的基准价格分别为 30、21、13 金币。

| 物品 | Unity 结算 |
| --- | --- |
| 狮王金雕 | 前后紧邻的存活队友各获得每枚金币 1% 的伤害加成。摇钱树枝获得的金币即时计入倍率，战后写入钱包。 |
| 魔导水晶 | 恢复实际造成的魔法和火焰生命伤害，按混合伤害中各部分的实际结算量取值。 |
| 绝缘灵珠 | 免疫非物理伤害，混合攻击中的物理部分照常结算。 |
| 摇钱树枝 | 每次发起攻击取得 2 金币，追加攻击与反击各自计数，贯穿多目标的单次攻击只计一次。 |
| 祈风铃 | 每个可结算的伤害分量增加 1 点。 |

处刑者面具的描述和伤害类型已改为真实伤害。

| 档位 | 本次定档的装备 |
| --- | --- |
| T1 | 狮王金雕、魔导水晶、绝缘灵珠 |
| T2 | 摇钱树枝、祈风铃、余响圣杯 |
| T3 | 吞金兽 |

每只余响圣杯增加 2 点能量上限，已加入战斗掉落池。吞金兽需补全摧毁装备后产生的效果，再开放掉落。

## 技能和性格

技能图鉴收录 20 项技能的效果、费用、学习限制和图标。[Unity 资源](../Assets/RaidPartyManager/PrototypeData/SkillCatalog.asset) · [技能图标总览](Previews/SkillIcons.jpg)

每项技能在战斗回放中有对应的逐帧特效。施法、命中和延后生效的播放时机见[技能特效说明](SkillEffects.md)。

队伍编辑的共享背包有「装备」和「技能书」两个书签。将技能书拖入符合职业条件的技能槽，角色学会该技能并消耗这一本书。已有技能时直接覆盖，旧技能被遗忘，也不会返还技能书。1 阶角色有 1 槽，2 阶角色有 2 槽。已学技能随角色进阶保留，不能卸回背包，同一角色也不能重复学习同一技能。单独的战斗演练开局提供每种书各一本供测试。学会的技能可由角色在自动战斗中施放，费用以能量计。

| 档位 | 技能书 |
| --- | --- |
| T1 | 熊熊烈火、极度冰点、闪电鞭、金钟罩、猩红收割、震慑八方 |
| T2 | 战争咆哮、阳光普照、妙手回春、万箭齐发、星陨术、横扫千军、毒瘴爆发、火眼金睛、裂地震击 |
| T3 | 坚如磐石、血肉盛宴、闪身步、英雄赞歌、穿云箭 |

战斗先按关卡类型抽档位，再从同档装备和技能书中抽取物品。普通战掉落一件，T1 概率 30%，T2 或 T3 合计 70%。精英战提供两件供选一，每次抽选的 T1 概率 50%，T2 或 T3 合计 50%。Boss 战按击败的 Boss 提供专属装备与技能书二选一，另给金币和一件随机装备（10% T0、30% T1、60% T2／T3）。岩石铠甲是常规 T1 装备。玩家界面隐藏档位。

[战斗规则](PrototypeRules.md)记录八种新性格的目标选择及站位行为。己方角色的性格参与行动决策。敌方按自身招式和目标规则行动。

## 2026-11-19 低语墓园增补

新增 23 普通、5 精英、2 Boss，序号 24–53，包含属性、占格、62 项行动的概率、目标与效果，以及对应立绘与六类动作。配置源与逐名说明见[低语墓园](WhisperingGraveyard.md)。两套固定队伍的 2200 场试算另存为 `WhisperingGraveyardBalance.csv`。

首次制作时无法访问原共享 Excel，因此先生成独立的增补表，含怪物图鉴、行动图鉴、规则与难度、难度试算四个工作表。仓库归档为 [WhisperingGraveyard.xlsx](WhisperingGraveyard.xlsx)。

用户随后提供了《讨伐队经理-图鉴 副本.xlsx》。已在其「敌人图鉴」第 25–54 行追加序号 24–53，合并版见 [Bestiary-WithGraveyard.xlsx](Bestiary-WithGraveyard.xlsx)，并放入同步 Obsidian 的 `敌人图鉴/低语墓园/`。共 53 名敌人：40 普通、9 精英、4 Boss。新增第三行为及概率、所属区域、占格和立绘列，共 62 项墓园行动与 30 张内嵌立绘。

原 8 个工作表的名称和顺序保留，原有敌人 A1:O24 的单元格内容与格式保留。其他 7 个工作表、音效原生表、原有共享字符串及工作簿设置按原文件部件保留并核对。重新导入后确认原有值和公式无变化、新增行动概率分别合计 100%，并核对新增范围和立绘显示。本次更新的是本地合并副本，未回写在线共享原表。

复现入口：在独立输出目录备份原件和生成的中文形象说明，使用 `Tools/MergeGraveyardWorkbook.mjs --inspect` 检查并预览；用 `--merge` 写入；运行 `Tools/PreserveGraveyardWorkbook.py` 保留未修改的原生部件；最后用 `--verify` 重新导入核对。JavaScript 与 lxml 使用 Codex 的捆绑运行时。
