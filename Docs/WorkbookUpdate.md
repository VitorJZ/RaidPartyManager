# 图鉴更新

以 2026 年 11 月 18 日的《讨伐队经理-图鉴.xlsx》为准。与上次装备定价时的快照相比，本次改动集中在装备、技能和性格。角色、敌人、区域和状态的规则表沿用原有内容。

## 装备

演练背包有下列 5 种装备，每种 4 件。档位用于战斗掉落。这批装备的商店价格待定。

| 物品 | Unity 结算 |
| --- | --- |
| 狮王金雕 | 前后紧邻的存活队友各获得每枚金币 1% 的伤害加成。摇钱树枝获得的金币即时计入倍率，战后写入钱包。 |
| 魔导水晶 | 恢复实际造成的魔法和火焰生命伤害，按混合伤害中各部分的实际结算量取值。 |
| 绝缘灵珠 | 免疫非物理伤害，混合攻击中的物理部分照常结算。 |
| 摇钱树枝 | 每次发起攻击取得 1 金币，追加攻击与反击各自计数，贯穿多目标的单次攻击只计一次。 |
| 祈风铃 | 每个可结算的伤害分量增加 1 点。 |

处刑者面具的描述和伤害类型已改为真实伤害。

| 档位 | 本次定档的装备 |
| --- | --- |
| T1 | 狮王金雕、魔导水晶、绝缘灵珠 |
| T2 | 摇钱树枝、祈风铃、余响圣杯 |
| T3 | 吞金兽 |

余响圣杯把装备者的能量上限设为 4，已加入战斗掉落池。吞金兽需补全摧毁装备后产生的效果，再开放掉落。

## 技能和性格

技能图鉴收录 20 项技能的效果、费用、学习限制和图标。[Unity 资源](../Assets/RaidPartyManager/PrototypeData/SkillCatalog.asset) · [技能图标总览](Previews/SkillIcons.jpg)

每项技能在战斗回放中有对应的逐帧特效。施法、命中和延后生效的播放时机见[技能特效说明](SkillEffects.md)。

队伍编辑的共享背包有「装备」和「技能书」两个书签。将技能书拖入符合职业条件的空技能槽，角色学会该技能并消耗这一本书。1 阶角色有 1 槽，2 阶角色有 2 槽。已学技能随角色进阶保留，无法拆卸、替换或重复学习。单独的战斗演练开局提供每种书各一本供测试。学会的技能可由角色在自动战斗中施放，费用以能量计。

| 档位 | 技能书 |
| --- | --- |
| T1 | 熊熊烈火、极度冰点、闪电鞭、金钟罩、猩红收割、震慑八方 |
| T2 | 战争咆哮、阳光普照、妙手回春、万箭齐发、星陨术、横扫千军、毒瘴爆发、火眼金睛、裂地震击 |
| T3 | 坚如磐石、血肉盛宴、闪身步、英雄赞歌、穿云箭 |

战斗先按关卡类型抽档位，再从同档装备和技能书中抽取物品。普通战掉落一件，T1 概率 30%，T2 或 T3 合计 70%。精英战和 Boss 战提供两件供选一，每次抽选的 T1 概率 50%，T2 或 T3 合计 50%。玩家界面隐藏档位。

[战斗规则](PrototypeRules.md)记录八种新性格的目标选择及站位行为。己方角色的性格参与行动决策。敌方按自身招式和目标规则行动。
